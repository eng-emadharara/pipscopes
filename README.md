# TrustTrader

منصة تقييمات (مثل Trustpilot) لقنوات التوصيات، خدمات نسخ الصفقات، ومقدمي خدمات التداول.

## المزايا

- **صفحة لكل مقدم خدمة**: نوع الخدمة، التصنيف، الأسواق، التسعير، رابط قناة التيليجرام وعدد المشتركين، وروابط السوشيال ميديا، والتقييم الحالي.
- **تقييمات المستخدمين**: تقييم عام (1-5)، تقييم حسب 4 معايير، أسباب إيجابية/سلبية، مدة التجربة، مع **خيار إظهار الاسم أو النشر كمستخدم مجهول** (الإدارة ترى الهوية دائماً).
- **تحليل سبب التقييم**: توزيع النجوم، متوسط كل معيار، أكثر الأسباب تكراراً، اتجاه آخر 90 يوماً، وملخص نصي تلقائي مع تنبيهات عند وجود مؤشرات خطيرة (`app/Services/RatingAnalysis.php`).
- **نموذج "أضف مقدم خدمة"** على الموقع (`/submit`) لإرسال البيانات للإدارة.
- **لوحة تحكم** (`/admin`) مبنية على Filament: إدارة مقدمي الخدمة، التصنيفات، التقييمات (نشر/رفض/رد مقدم الخدمة)، طلبات الإضافة (تحويلها لمقدم خدمة بضغطة)، المستخدمين، وإحصائيات.

## التشغيل محلياً

```bash
composer install
npm install && npm run build
cp .env.example .env && php artisan key:generate   # إن لم يكن موجوداً
php artisan migrate --seed
php artisan storage:link
```

الموقع يعمل عبر Herd على `http://trusttrader.test`.
بيانات حساب المدير الافتراضي موجودة في `database/seeders/DatabaseSeeder.php` (يمكن تغييرها عبر `ADMIN_EMAIL` و`ADMIN_PASSWORD` في `.env` قبل تشغيل الـ seeder).

## تعدد اللغات

الموقع يدعم العربية (اللغة الأساسية، RTL) والإنجليزية (LTR)، مع زر تبديل في الهيدر وروابط اللغات في الفوتر. يمكن أيضاً فتح أي رابط بلغة محددة عبر `?lang=en`.

- **نصوص الواجهة:** المفاتيح هي النص العربي نفسه، وترجمتها في `lang/en.json`. أما القوائم (المعايير، الأسباب، التسعير…) وجمل تحليل التقييم ففي `lang/{ar,en}/trust.php`.
- **المحتوى:** اسم ووصف التصنيف، ونوع الخدمة والأسواق والنبذة لمقدم الخدمة، تُدخل بالعربية في الحقول الأساسية، وبباقي اللغات من قسم "الترجمات" في لوحة التحكم. أي حقل غير مترجم يظهر بالعربية.
- **لوحة التحكم** تبقى بالعربية دائماً.

**لإضافة لغة جديدة** (مثلاً الفرنسية): أضفها إلى `locales` في `config/trust.php`، ثم أنشئ `lang/fr.json` و`lang/fr/trust.php`. بعدها يظهر تبويب ترجمتها تلقائياً في لوحة التحكم.

## الإعدادات

- `config/trust.php`: المعايير، الأسباب الإيجابية/السلبية، خيارات التسعير، وروابط السوشيال.
- `REVIEWS_REQUIRE_APPROVAL=true` في `.env` لجعل التقييمات الجديدة تنتظر موافقة الإدارة قبل الظهور.
